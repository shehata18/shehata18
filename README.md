## Featured Projects

### 🎓 International Students CRM
`Laravel` `Filament` `REST API` `MySQL` `RBAC` `VPS`

A full-featured CRM built for agencies managing international students studying in Egypt. Covers the complete student lifecycle — from first contact through university enrollment and ongoing academic follow-up.

**Key features:**
- Multi-stage student lifecycle with operational, academic, and financial tracking
- RBAC with dynamic permission assignment per admin (view, create, edit, manage per module)
- Universities, faculties, and specializations management
- Documents module with categorized file uploads (passport, certificates, visa docs, contracts)
- Payments module with partial payments, overdue tracking, and per-student statements
- Student portal with personal follow-up, payment status, and issue submission
- Activity log and timeline for every student record
- Passport-number-based search and multi-field filtering
